The excuse an AI agent gives its human for missing a deadline — one line,
at most 160 characters. `LINE.txt` holds the line; `main.ts` checks it is a
single line of 1 to 160 characters and writes it to `/output/entry.txt` for
the judge to read.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
